## En français

Je suis le fondateur de KOM-5A. Nous avons relié la publication d'une offre, la découverte de la personne qui la porte et les moyens de prendre contact dans un même parcours. Cet espace donne accès à la documentation publique du projet : comprendre la plateforme et K5A, préparer une publication et retrouver les applications officielles.

Une correction à suggérer ? Ouvrez une issue dans [le dépôt du projet](https://github.com/SKORPION1200/kom-5a/issues). Pour une question de compte ou de confidentialité, utilisez le [contact officiel](https://kom-5a.com/contact). Pour une faille, consultez les [consignes de signalement privé](https://github.com/SKORPION1200/kom-5a/security/policy).
